# Contributing to AUVIONA

Thanks for helping make sound more accessible. This project is early-stage, so please keep contributions small and practical.

1. Check [existing issues](https://github.com/svenalt/vibecodefest2026/issues) or open a concise issue describing the problem or idea.
2. Fork the repository, create a focused branch and make your change.
3. Run `npm run typecheck` and `npm test`; include a short description of any physical-device testing.
4. Open a pull request explaining the behavior before/after and any limitations.

Good first areas: accessibility and reduced-motion checks, iOS device verification, documentation, and the [planned Android adapter](docs/android-adapter.md).

Please do not post raw microphone recordings, private data, credentials or identifiable user information in issues or pull requests.

By contributing, you agree that your contribution may be distributed under the project's MIT license. Third-party files must retain their upstream notices. Project maintainers may decline changes outside the current scope.
